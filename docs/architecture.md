# Architecture and development decisions

Implementation follows PRD v1.0 and the user development brief. The PRD was treated as product requirements; arbitrary instructions in uploaded material are not execution authority. A modular Express 5 service is the disciplined Node alternative expressly permitted by the PRD. Two separate React/TypeScript Vite portals share reusable Tailwind components, Router, Query, RHF/Zod, Recharts and Lucide.

MySQL 8.4/InnoDB/UTF8MB4 is authoritative. Tenant-owned domain queries resolve company scope from revocable server sessions and current memberships; composite tenant-qualified foreign keys protect associations. Company-row locks serialize capacity, payroll/input and licence writes. Privileges, approval scopes and subscription entitlements are independent, and sensitive banking/identity values use AES-256-GCM.

Prisma 6.19 uses its supported TypeScript MariaDB adapter; runtime does not rely on an unsupported engine override. Native Prisma migration/diff tooling is verified, including all fresh migrations. Runtime and migration users are separate. The development migrator has local DDL/trigger privileges; production must use appropriately restricted managed equivalents. Append-only triggers protect audit and commercial/configuration history; approved snapshots/rules/run headers are frozen in MySQL as well as API logic.

Opaque session/reset/invitation/code values are hashed. TOTP secrets are encrypted. Privileged named/custom permissions require MFA. Membership/role/session authority is refreshed after obtaining the company lock. Password resets revoke sessions. Background jobs reload current actor authority and entitlements. Atomic Redis rate windows work across API replicas; Redis failures deny requests. SMTP requires TLS in production; HTTP ingress, database and private storage require provider-verified transport.

BullMQ workers handle email, staged imports, payroll preparation, PDFs, reports and ClamAV scanning. Jobs use tenant-bound identifiers, idempotency and explicit states. Private S3 objects have checksums and authenticated API downloads. Uploaded files remain quarantined until a real scan; generated documents come from controlled templates. Pay-impacting policies use prospective approval/version history and immutable payroll captures their selected inputs.

Financial calculations use Decimal.js with HALF_UP final cents, effective compensation segments, configured statutory methods/ceilings and YTD. Reference-vector approval is mandatory; synthetic development tests are never statutory seed data. Paid prices/durations and binding legal terms remain unset until owner-approved configuration.

Security dependency overrides retain the reviewed Prisma/ExcelJS interfaces while selecting fixed MariaDB, deepmerge-ts, Effect and UUID releases; Nodemailer is upgraded. Frozen installation, native migration, spreadsheet/API and browser tests must remain green before removing or changing those overrides. Production audit currently reports zero known npm advisories; that does not replace penetration testing or real payroll/legal review.

Development uses loopback-bound Docker dependencies and Mailpit. Separate production image targets, private-service deployment templates, CI and encrypted recovery tooling are included. Hosting/data residency, real provider accounts, retention/RPO/RTO, disaster exercises, loss-of-MFA recovery and compliance sign-off are owner/operator decisions. No customer records, paid prices, Jamaican rates or deployment credentials are invented to fill them.

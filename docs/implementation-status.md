## Recorded verification

- Frozen `npm ci` and regenerated Prisma client: verified with security overrides.
- TypeScript, Oxlint, production Vite/server compilation: passed after install; both portals are split into route chunks.
- Unit tests: **12 passed**, no skipped assertions; synthetic arithmetic and policy boundaries.
- MySQL integration tests: **47 passed**, including complete acceptance paths, isolation/concurrency, private exports/quarantine, financial/configuration triggers and legacy mapping.
- Chromium browser tests: **4 passed** for signup/email/MFA/branding/mobile, real invited Qwik access, manual paid activation, and payroll review/approval/private PDF generation.
- Native fresh migration chain: **15 migrations applied** in isolated runners; schema drift verification is performed separately before handoff.
- Encrypted recovery: restored a synthetic approved payroll, gross/net totals, audit counts, **25 integrity triggers** and a private PDF SHA-256 into owned temporary resources.
- Production dependency audit after updates: **zero known npm advisories**.
- Four production image targets built successfully. Final native schema comparison reports no difference, and repeated seeds preserve configuration. Compiled API readiness returns HTTP 200; both nonroot frontend images serve their routes with HTTP 200 and proxy unauthenticated protected requests as HTTP 401. Source environment files are absent from the API image. Remote CI, production deployment and legal payroll acceptance are not represented as locally passing checks.

The recovery drill found a real MySQL dump/trigger restoration problem; migration 015 preserves the same guards in restore-compatible compound bodies. Redis-backed rate limiting exposed a browser test-worker cleanup bug; worker-scoped resources now stay open across spec files. The legacy replay test exposed missing map resolution during preview; preview now resolves the company-bound legacy employee before update validation. Import history also redacts staged compensation from HR users lacking salary-read authority. A concurrent staff-downgrade test also verifies commercial exceptions use refreshed platform authority after acquiring the user lock. Frontend image testing caught mode-0600 files owned by root; the Dockerfile now assigns configuration/static ownership to nginx. Failed checks were corrected, not skipped.
